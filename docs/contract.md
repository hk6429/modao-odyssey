# 墨島字旅 v1 契約

2026-10-04：以 Word Odyssey 字旅的地圖、分批學習、複習、行囊、手札為參考，建立獨立國字注音網站。原專案不變。

- 視覺：台灣國風潑墨淡彩。Q版角色頭：身＝1：1，不是圖片比例。
- 八站：大稻埕、九份、陽明山、鹿港、日月潭、阿里山、安平、墾丁；每站10章，共80章。
- 來源：字字珠璣國小與國中字音字形JSON，4870筆。完全相同題幹＋答案合併3筆，4867題。保留來源ID與原題/選項/答案/解析，單位稱「題」，不宣稱4867個國字。
- 實戰考題有不同的複選schema，本版不納入，不改造原始正解。
- 每次3/5/10新題；先複習最多10道到期題，翻卡學習，再完成試煉。錯題解析及重答，提示與錯誤不算首次獨立答對。完成一批才一次入帳；中途關閉可接續。
- 複習有到期時間；熟練需3個不同日期首次無提示答對，且至少1次輸入回憶。複習不重複XP。
- 三名旅伴、八站各自敘事、每區二選一故事回應、80章事件與回收，故事不能替代學習解鎖。
- 本機儲存、JSON匯出/匯入、驗證版本及題目ID；可用訪客模式。未提供跨裝置雲端同步，不冒用原站登入。
- 原生HTML/CSS/JS、無付費API；不依賴線上AI。
- 驗證：來源逐欄比對、唯一性/課程覆蓋、原子入帳與錯題複習、備份驗證、實際桌面/手機完整一批和重載。
- 部署尚未授權；先交付本機預覽及GitHub備份。
