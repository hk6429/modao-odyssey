# 墨島字旅

正式網站：https://modao-odyssey.hk6429.workers.dev/

把字，寫回山海之間。以「字旅」的冒險學習架構為參考，使用「字字珠璣」國字注音、字音字形題庫的台灣山海老街學習網站。

![墨島字旅](assets/hero.webp)

## 本機啟動

需要 Node.js 22 以上。網站本身沒有執行期套件、付費 API 或線上 AI 依賴。

```sh
npm run build
npm start
```

開啟 http://127.0.0.1:4198 。使用 `PORT` 環境變數可調整連接埠。伺服器只提供 `dist/` 白名單建置內容，不提供來源資料、測試、文件或設定。

## 一座島，八段故事

| 地點 | 任務 | 印記 |
|---|---|---|
| 大稻埕 | 修復茶行招牌，讓家書找到收信人 | 街聲 |
| 九份 | 讀懂燈籠祝福，照亮晚歸人的路 | 燈語 |
| 陽明山 | 辨清路標聲音，替山徑找回方向 | 風音 |
| 鹿港 | 找回老匠人的落款，留下手藝的名字 | 巷憶 |
| 日月潭 | 修復湖上信箋，把心意送往彼岸 | 湖信 |
| 阿里山 | 補回森林車票，陪旅人安心出發 | 林語 |
| 安平 | 分辨樹屋藏頁的字形，重訂老街記憶 | 根書 |
| 墾丁 | 完成燈塔書卷，把學會的字帶回生活 | 海歸 |

故事為原創虛構，結合真實地名與景觀，不冒充地方史料。三位旅伴：阿青、小硯、墨寶。每站有二選一故事回應、十個章節事件與完成結局；故事選擇不能跳過學習解鎖。

台灣國風潑墨與淡彩插畫由內建 imagegen 產生；Q 版人物的頭部高度與身體（含腿）高度比例為 1：1。兩张四格圖集呈現八地景，CSS 定位顯示；原 PNG 與 WebP 均保留。提示詞見 [圖像來源](docs/art-prompts.md)。

## 學習方式

- 8 個地區、80 章、4,867 道不重複題目，每章60或61題。
- 依原題難度易、中、難排列，同難度先國小再國中；這是自編練習順序，不是官方能力分級。
- 每次選3、5或10道新題；先複習最多10道到期題，再讀字卡、完成試煉。
- 答錯顯示對應選項解析，錯題排到後面再次作答；完成整批才增加已學題數及XP。
- 每道新題給10 XP；複習與重開頁面不重複給分。未完成練習及答題回饋可接續。
- 到期複習輪替選擇辨認與文字輸入；注音輸入含聲調，一聲可省略，允許空白。
- 使用提示、同輪答錯再重答都不算首次獨立答對。熟練需至少3個不同日期到期複習首次無提示答對，並含至少1次輸入回憶。
- 行囊可搜尋國字、注音、詞語並篩選；手札記錄每批成果，可匯出／匯入JSON。

## 題庫來源與限制

採用「字字珠璣」的 `ziyin-zixing-elementary.json`（1,532筆）與 `ziyin-zixing-junior.json`（3,338筆）。原始4,870筆以相同題幹＋答案去重，合併3筆，保留4,867筆。`sourceRefs` 保留合併前來源ID，所有題幹、選項、答案、解析與難度維持原資料。來源雜湊與統計見 [資料稽核](docs/data-audit.json)。

同一國字可以出現在不同語境題，因此計數單位是「題」，不是不同國字數。來源內包含官方解答取材及自編題，逐題保留標示；本次只驗證與來源專案完全一致，未宣稱重新人工對照全部官方試卷。實戰考題因複選格式不同，本版不納入。

不將第三方官方試題或來源素材重新宣告為本專案自有的開放授權。再利用原始素材時，應依各來源條件處理。

## 儲存

僅使用瀏覽器 localStorage，免登入，不上傳學習資料。一般旅程使用 `modao-odyssey-v1`；`?test=1` 使用獨立測試存檔。清除瀏覽器資料、換瀏覽器或換裝置不會自動帶走進度；請使用手札備份。尚未串接 Google、雲端同步或學習航站。

## 驗證

```sh
npm test
```

涵蓋4867題逐欄來源比對、唯一性、80章完整遍歷、錯題重答、原子入帳、草稿還原、提示／熟練紀錄與備份驗證。

瀏覽器驗證另需安裝開發套件並啟動網站：

```sh
npm ci

```

預設使用 macOS Google Chrome，可用 `CHROME_PATH` 指定既有 Chromium。測試使用隔離瀏覽器與測試存檔，不讀使用者的 Chrome 個人資料。報告見 [瀏覽器驗證](docs/browser-qa.json)，截圖輸出至不提交的 `artifacts/`。

## 沉浸式故事漫遊

滿版場景搭配透明背景兩頭身旅伴，逐句閱讀故事後接受任務。行旅目錄收納朝代／景點與章節；未解鎖章節可探看與試讀，正式學習仍依序進行。首頁與預習不改寫學習成果，原本機存檔與匯入匯出格式保持相容。首站採獨立高解析場景，其餘沿用原水墨地景圖集。

## 選擇題鍵盤操作

A：← 或 1；B：↑ 或 2；C：↓ 或 3；D：→ 或 4。依畫面選項順序作答；題目未提供的選項不接受按鍵。答對直接進入下一題或完成畫面，答錯停留解析，讀完再按繼續。輸入框、選單、中文／日文輸入法組字與系統快捷鍵不攔截；長按與雙擊不連續作答。
